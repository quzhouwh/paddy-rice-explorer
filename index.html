Model and data format

Climate change for each year is evaluated as f(T + ΔT, P + ΔP) − f(T, P), with f(T, P) = β₁T + β₂T² + β₃P + β₄P² + β₅TP. Scenario yield equals observed yield plus Δf, in ton/ha. The shaded band shows the supplied within-field yield SD.

In QGIS, export kien_giang_field_seasons.shp using Save Features As → GeoJSON → EPSG:4326. Include field_id, year, season, yield_mean, yield_std, temp_c, precip, and coef_1–coef_5. Place the exported file at data/kien_giang_field_seasons.geojson relative to this page. The map loads it automatically.
